
## 👨‍💻 About Me:

C++ developer with commercial experience in teams of five to nine people, both in-office and remote.

🔧 I work on distributed industrial automation systems: TCP networking, device protocol implementation, multithreaded telemetry processing, and history storage in PostgreSQL.

🚀 Experienced across the full development cycle - from requirements gathering to automated release pipelines with test coverage and CI/CD.

⚡ Interested in building high-performance, fault-tolerant distributed systems in C++.

🎮 Outside of work, I build C++ trading bots for in-game item marketplaces: cross-marketplace price comparison, automated buying and listing via orders, and API integration.
